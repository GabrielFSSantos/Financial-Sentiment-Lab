# Fontes

O deck PDF usa **Latin Modern** (substituto metricamente próximo no LaTeX) e cores UFSJ definidas em `qualificacao.tex`.

Para paridade com o template Google Slides institucional (Arial), instale Arial no sistema ou ajuste o preâmbulo Beamer para `fontspec` + XeLaTeX, se a banca exigir pixel-match ao modelo UFSJ.
