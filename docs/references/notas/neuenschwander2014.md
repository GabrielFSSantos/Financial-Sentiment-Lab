# Neuenschwander et al. (2014) — Sentiment Analysis for Streams of Web Data

**Referência:** WebMedia 2014 — caso de estudo em mercados financeiros brasileiros.

## Tese central

Análise de sentimento em fluxos contínuos de dados web é tecnicamente desafiadora; extração, pré-processamento e alinhamento temporal não são triviais no contexto BR.

## O que tomamos no lab

- Justifica cautela na **coleta** (F0): scraping multiportal pode introduzir ruído estrutural.
- Suporta tratar gênero jornalístico (roundup vs focal) como hipótese de qualidade, não como fato presumido (F4).

## Diferença no nosso caso

- Estudo foca streams/web; nós usamos corpus tabular strict com validação semanal contra SBSP3.
