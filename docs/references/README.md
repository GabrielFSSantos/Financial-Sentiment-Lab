# Referências bibliográficas

- **BibTeX:** [bibliografia.bib](bibliografia.bib) (espelhado na dissertação em `Dissertacao_PPGCC/referencias.bib`)
- **PDFs:** [pdfs/](pdfs/) — convenção `autorano_tema.pdf` (minúsculas, underscore)
- **Notas de leitura:** [notas/](notas/) — o que o lab toma de cada obra; ver também [decision-register](../research_trail/decision-register.md)
- **Citação em prosa (markdown):** [citation-conventions](../research_trail/citation-conventions.md)

Obras citadas sem PDF local constam no `.bib` com DOI e nota correspondente (ex. Fleiss 1971).
